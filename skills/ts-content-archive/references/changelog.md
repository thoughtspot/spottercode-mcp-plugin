## Intentional differences from cs_tools

| Difference                                | cs_tools                                                        | This skill                                                                                 |
| ----------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| No `--org` switch                         | Switches Org with `--org` before acting                         | Acts only on the Org the token is scoped to; re-run with another token for another Org     |
| No `--no-prompt`                          | Can skip the confirmation prompt                                | Confirmation is always required; deletion needs the count (or tag name) typed back         |
| Failed deletes keep the tag               | Deletes the tag in the same batch as the objects                | Deletes the tag only once every object delete succeeded, so failures can be retried        |
| Ask before deleting unexported objects    | Deletes regardless of export failures                           | Asks before deleting objects whose TML export failed; on N they are kept                   |
| Org-name filter whenever Orgs are enabled | Adds `[Org Name]` only when `--org` is passed                   | Adds `[Org Name].'{org_name}'` to every activity window whenever Orgs are enabled          |
| Nested group expansion                    | v1 group users, assigned and inherited groups                   | REST v2.0 search groups, union of `users` over the group and all `sub_groups`, recursively |
| System accounts excluded                  | Docstring promises it; never applied                            | Always excludes `tsadmin`, `system`, `su` by GUID and by author name                       |
| Untag offers unassign or delete           | `untag` always deletes the tag                                  | Asks: unassign from Answers/Liveboards only, or delete the tag (cs_tools behaviour)        |
| Tag assign batching                       | One object per call, 15 at a time                               | Up to 100 per call; a failed batch is retried one per call                                 |
| Report is a CSV file                      | `archiver_report` table via a syncer                            | Optional CSV with the same columns, or printed in a code block without a shell             |
| Export-only needs a directory             | Silently exports nothing without `--directory`                  | Asks for a directory                                                                       |
| Individual author filters                 | None; group filters only                                        | Optional only/ignore by individual author, combined with the group filters (all must hold) |
| ADMINISTRATION preflight                  | No up-front privilege check                                     | Step 1 stops before any question unless the token has ADMINISTRATION                       |
| Ignore tags matched by name               | Resolves tag names to GUIDs, matches GUIDs                      | Matches tag names on each object; same result                                              |
| Typed confirms                            | `y/N` prompt                                                    | Object deletion needs the count typed back; tag deletion needs the tag name typed          |
| Partial metadata fetch                    | Silently drops a type whose fetch failed (`metadata.py` ~54-57) | Reports the failed types and asks continue or stop                                         |
| Preview-only options                      | None                                                            | Identify and Remove offer a preview-only (dry run) choice                                  |
| Identify preview AUTHOR column            | Prints the author GUID (`app.py:383`, a cs_tools bug)           | Shows the author name                                                                      |
