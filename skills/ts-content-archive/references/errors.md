# Error Handling

What to do for each known failure in [../SKILL.md](../SKILL.md). Never guess an
operation path or shape, and never fall back to a Primary Org token.

| Symptom                                                                                     | Action                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Session lookup returns 401, or user lacks `ADMINISTRATION`                                  | 401: the session expired; ask the user to reconnect the Spotter Code MCP server (`/mcp`). No `ADMINISTRATION`: stop immediately, because archival is admin-only                                                                                                                                  |
| Both only/ignore given for authors or groups, or a group name isn't found                   | Both given: stop, and ask the user to pick one. Not found or empty: report and re-ask (group names are case-sensitive)                                                                                                                                                                           |
| TS: BI Server not found or not queryable                                                    | Identify only: stop. This skill can't determine activity without it, so never guess staleness from modification date alone. In a non-Primary Org, report that this Org is unsupported (open item 1). Never switch to a Primary Org token, because tagging and deletion would hit the Primary Org |
| `min [Timestamp]` cell is not a number after unwrapping `{"v": {"s": …}}`                   | Stop and ask the user for an explicit query-inactivity N. Never guess the lookback window                                                                                                                                                                                                        |
| An activity search times out on a window                                                    | Narrow the window (for example 3 days instead of 7) and retry that window only. If it still fails, stop: a missing window would make active content look stale                                                                                                                                   |
| A metadata search page fails partway (Identify 4c, Untag/Remove Step 4)                     | Report the type and `record_offset` that failed, and ask whether to continue with the partial set (preview marked PARTIAL) or stop                                                                                                                                                               |
| An assign/unassign tag batch call errors                                                    | Retry that batch one object per call. Report each object that still fails, with its error message, and count only the successes                                                                                                                                                                  |
| Untag: no tag matches the name (case-insensitive)                                           | Report `No tag found with the name '{input}'.` and stop                                                                                                                                                                                                                                          |
| Untag (b) / Remove: delete metadata rejects the tag GUID                                    | Retry with the delete tag operation on the same id. If that also fails, report it; the objects are unaffected                                                                                                                                                                                    |
| Create tag reports the tag already exists, or an object is still visible after Remove       | Tag exists: not an error, reuse it. Deletion can take a moment to propagate, so re-check before escalating                                                                                                                                                                                       |
| Remove: the typed count doesn't match `{n}`, or Untag (b): the typed tag name doesn't match | Stop. Delete nothing. Re-show the preview and ask again                                                                                                                                                                                                                                          |
| CSV report can't be written (no shell, or the path isn't writable)                          | Print the CSV in a code block instead, and say plainly that no file was written                                                                                                                                                                                                                  |
| `get-rest-api-reference` has no entry for an operation described here                       | Stop, and name the operation that couldn't be resolved. Never guess a path or shape                                                                                                                                                                                                              |
